# GOLD Analysis Platform

A standalone GOLD/XAUUSD market intelligence and chart analysis platform.

## Current Status

Initial platform infrastructure and repository architecture are being established.

## Core Goals

- Interactive GOLD/XAUUSD chart analysis
- Multiple timeframe support
- Market data ingestion and storage
- Proprietary technical indicators
- Saved chart layouts and drawings
- Strategy research and performance analysis
- Future public-facing analysis website
- MT5 remains the execution environment

## Repository Structure

- `apps/analysis` - Main chart analysis application
- `apps/web` - Future public website
- `packages/charting` - Charting components and utilities
- `packages/indicators` - Technical and proprietary indicators
- `packages/market-data` - Market data ingestion and normalization
- `packages/database` - Database access and schemas
- `packages/ui` - Shared interface components
- `packages/config` - Shared configuration
- `supabase` - Database migrations and seed data
- `docs` - Architecture and engineering documentation
